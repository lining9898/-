## 方法与边界

PDF 内嵌文本对汉字和公式的提取不可靠。本次以 PDF 页图人工核对有限条文，保存的是简短规则摘要，不是规范原文；页面索引和摘要不自动升级 `Evidence.verificationStatus`。网页采用本地中文词项检索，随后执行独立数值算例，对比函数结果、判定和未覆盖输入。它不是全文向量检索或大模型裁决，样例吻合也不代表函数在全部输入域正确。

在 `V=800 kN` 时，旧函数的“截面限制条件验算”会误判通过；按该条分段条件应不通过。现在 `h0/b≤4` 用 0.25，`≥6` 用 0.20，区间内线性内插。新增 3、4、5、6、7 的边界回归和能检出旧实现的审计器测试。

矩形梁原有最小配筋面积已按 `b·h` 计算，但结果栏的配筋率却按 `b·h0` 显示。现统一为第 8.5.1 条用于最小配筋验算的截面面积口径，并增加反查测试。有效高度配筋比是另一种工程量，不能混在该处不加说明地标为最小配筋验算的 `ρ`。
