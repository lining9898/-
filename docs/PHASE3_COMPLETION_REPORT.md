## 七、发现的原计算公式错误

### BUG 1：最小配筋率百分数转换错误

**位置**：`src/core/beam/flexure.ts` 第 214 行（修复前）

**原代码**：
```typescript
const rhoMin = Math.max(0.2, 45 * concrete.ft / steel.fy * 100) / 100;
```

**错误分析**：
- 规范原文：ρmin = max(0.20%, 45·ft/fy %)
- 45 × ft / fy 的结果是百分数的数值部分（如 0.17875 表示 0.17875%）
- 代码中又乘以 100，变成 17.875，然后除以 100 得到 0.17875
- 这被当作小数使用，即 17.875%，**完全错误**

**修复后代码**：
```typescript
const rhoMinPercent = Math.max(0.20, 45 * concrete.ft / steel.fy);
const rhoMin = rhoMinPercent / 100;
```

### BUG 2：最小配筋面积计算基准面积错误

**位置**：`src/core/beam/flexure.ts` 第 215 行（修复前）

**原代码**：
```typescript
const AsMin = rhoMin * input.b * h0 / 100;
```

**错误分析**：
- 规范 8.5.1 注5明确规定：受弯构件一侧受拉钢筋的配筋率应按**全截面面积**计算
- 对于矩形截面，即按 b × h 计算，**不是 b × h0**
- 代码中使用 h0（有效高度），不符合规范要求

**修复后代码**：
```typescript
const AsMin = rhoMin * input.b * input.h;
```
