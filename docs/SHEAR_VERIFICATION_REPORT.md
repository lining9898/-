## 一、PDF 原文提取结果

### 1.1 第 69 页 - 6.3.1 条（受剪截面限制条件）

**规范原文**（OCR 提取，已人工校正）：

> **6.3.1** 矩形、T 形和 I 形截面受弯构件的受剪截面应符合下列条件：
> 
> 当 hw/b ≤ 4 时
> 
> V ≤ 0.25βc·fc·b·h0  (6.3.1-1)

### 1.2 第 70 页 - 6.3.1 条续

**规范原文**：

> 当 hw/b ≥ 6 时
> 
> V ≤ 0.2βc·fc·b·h0  (6.3.1-2)
> 
> 当 4 < hw/b < 6 时，按线性内插法确定。
> 
> **式中**：
> - V —— 构件斜截面上的最大剪力设计值；
> - βc —— 混凝土强度影响系数：当混凝土强度等级不超过 C50 时，βc 取 1.0；当混凝土强度等级为 C80 时，βc 取 0.8；其间按线性内插法确定；
> - b —— 矩形截面的宽度，T 形截面或 I 形截面的腹板宽度；
> - h0 —— 截面的有效高度；
> - hw —— 截面的腹板高度：矩形截面，取有效高度；T 形截面，取有效高度减去翼缘高度；I 形截面，取腹板净高。

### 1.3 第 71 页 - 6.3.4 条（斜截面受剪承载力）

**规范原文**：

> **6.3.4** 当仅配置箍筋时，矩形、T 形和 I 形截面受弯构件的斜截面受剪承载力应符合下列规定：
> 
> V ≤ Vcs + Vp  (6.3.4-1)
> 
> Vcs = αcv·ft·b·h0 + fyv·(Asv/s)·h0  (6.3.4-2)
> 
> Vp = 0.05Np0  (6.3.4-3)
> 
> **式中**：
> - Vcs —— 构件斜截面上混凝土和箍筋的受剪承载力设计值；
> - Vp —— 由预加力所提高的构件受剪承载力设计值；
> - αcv —— 斜截面混凝土受剪承载力系数，对于一般受弯构件取 0.7；对集中荷载作用下（包括作用有多种荷载，其中集中荷载对支座截面或节点边缘所产生的剪力值占总剪力的 75% 以上的情况）的独立梁，取 αcv 为 1.75/(λ+1)，λ 为计算截面的剪跨比，可取 λ 等于 a/h0，当 λ 小于 1.5 时，取 1.5，当 λ 大于 3 时，取 3，a 取集中荷载作用点至支座截面或节点边缘的距离；

### 1.4 第 134 页 - 9.2.9 条（箍筋构造要求）

**规范原文**：

> **9.2.9** 梁中箍筋的配置应符合下列规定：
> 
> 2. 截面高度大于 800mm 的梁，箍筋直径不宜小于 8mm；对截面高度不大于 800mm 的梁，不宜小于 6mm。
> 
> 3. 梁中箍筋的最大间距宜符合表 9.2.9 的规定；当 V 大于 0.7ft·b·h0 时，箍筋的配筋率 ρsv [ρsv = Asv/(bs)] 尚不应小于 0.24ft/fyv。

## 二、代码实现与规范原文对比

### 2.1 受剪截面限制条件（6.3.1）

| 项目 | 规范原文 | 代码实现 | 是否一致 |
|------|---------|---------|---------|
| **公式** | V ≤ 0.25βc·fc·b·h0 (hw/b ≤ 4) | `VMax = 0.25 * betaC * concrete.fc * input.b * input.h0 / 1000` | ✅ 一致 |
| **βc 取值** | C50 及以下取 1.0，C80 取 0.8，中间线性内插 | `betaC = fcuK <= 50 ? 1.0 : Math.max(0.8, 1.0 - (fcuK - 50) * 0.02 / 3)` | ✅ 一致 |
| **hw 取值** | 矩形截面取有效高度 h0 | 代码中 hw = h0（隐含） | ✅ 一致 |
| **适用范围** | hw/b ≤ 4、4 < hw/b < 6、hw/b ≥ 6 三种情况 | 仅实现 hw/b ≤ 4 的情况 | ⚠️ 部分实现 |

**说明**：代码仅实现了 hw/b ≤ 4 的情况。对于矩形截面，hw = h0，常见梁的 hw/b 通常远小于 4（如 b=250, h=500, h0≈460 时，hw/b ≈ 1.84），因此仅实现第一种情况在工程实践中是合理的。但严格来说，代码应支持所有三种情况。

**核验结论**：✅ **VERIFIED**（在 hw/b ≤ 4 的适用范围内）

### 2.2 斜截面受剪承载力（6.3.4）

| 项目 | 规范原文 | 代码实现 | 是否一致 |
|------|---------|---------|---------|
| **基本公式** | V ≤ Vcs + Vp (6.3.4-1) | 代码中 Vp = 0（非预应力构件），仅验算 V ≤ Vcs | ✅ 一致 |
| **Vcs 公式** | Vcs = αcv·ft·b·h0 + fyv·(Asv/s)·h0 (6.3.4-2) | `Vcs = alphaCv * concrete.ft * input.b * input.h0 / 1000 + steel.fy * (Asv / input.stirrupSpacing) * input.h0 / 1000` | ✅ 一致 |
| **αcv（均布荷载）** | 一般受弯构件取 0.7 | `alphaCv = 0.7` | ✅ 一致 |
| **αcv（集中荷载）** | 1.75/(λ+1) | `alphaCv = 1.75 / (lambda + 1)` | ✅ 一致 |
| **λ 计算** | λ = a/h0 | `lambda = input.shearSpan / input.h0` | ✅ 一致 |
| **λ 限制** | λ < 1.5 取 1.5，λ > 3 取 3 | `lambda = Math.max(1.5, Math.min(3, lambda))` | ✅ 一致 |

**核验结论**：✅ **VERIFIED**

## 三、发现的问题

### 3.1 受剪截面限制条件未完整实现

**问题描述**：规范 6.3.1 条规定了三种情况（hw/b ≤ 4、4 < hw/b < 6、hw/b ≥ 6），代码仅实现了第一种情况。

**影响评估**：对于矩形截面梁，hw = h0，常见的梁截面 hw/b 通常远小于 4。例如：
- b=250, h=500, h0≈460 → hw/b ≈ 1.84
- b=300, h=600, h0≈560 → hw/b ≈ 1.87

因此在工程实践中，仅实现 hw/b ≤ 4 的情况是安全的。但如果用户输入非常窄高的截面（如 b=150, h=1000, h0≈960 → hw/b ≈ 6.4），代码将给出错误的结果。

**建议**：
1. 在输入校验中增加 hw/b 的范围检查，超出范围时给出警告
2. 完整实现三种情况的计算逻辑

**当前状态**：⚠️ **部分实现，在常见范围内 VERIFIED，超出范围需补充**
