## 1. 影响现有模块的逐条差异

### 1.1 第 4.1.2 条（混凝土强度等级最低要求）

| 项 | 内容 |
|---|---|
| 2015 年版原值 | 素混凝土结构 ≥ C15；钢筋混凝土结构 ≥ C20；采用 400MPa 级钢筋时 ≥ C25。 |
| 2024 修订后 | 素混凝土结构 ≥ **C20**（C15 删除）；钢筋混凝土结构 ≥ **C25**（C20 删除）；采用 400MPa 级钢筋时 ≥ C25；500MPa 级钢筋时 ≥ C30。 |
| 适用条件 | 混凝土结构设计基本材料要求 |
| 影响模块 | 所有混凝土模块（材料参数选择） |
| 代码位置 | `src/core/shared/materials.ts`（CONCRETE_PARAMS） |
| 代码当前取值 | C20~C50；未含 C15；未含 C55~C80 |
| 差异 | **代码未提供 C15，但也未限制最低 C25**；用户选 C20 时在 2024 版已不允许。 |
| Evidence 状态 | REVIEW_REQUIRED |

## 3. 新产生的待核差异项

1. **8.5.1 → GB 55008 强制引用**：GB 55008-2021 本工作区不可见，须后续取得正式出版物后补条文映射。
2. **4.1.2 最低强度等级**：代码允许 C20，但 2024 版钢筋混凝土结构最低为 C25；须在输入校验中加警告或限制。
3. **9.1.2 板厚跨厚比**：现有板模块未建 Evidence，须补。
4. **3.5.3 耐久性**：现有模块未涉及耐久性计算，暂无影响。
