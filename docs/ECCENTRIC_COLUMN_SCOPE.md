# 偏心受压柱：当前范围与证据

本模块只处理矩形截面、单轴单曲率、对称双层纵向钢筋的正截面截面承载力。输入的 `M0` 为尚未计入附加偏心距的一阶弯矩设计值。

## 已使用的原始依据

原始文件：`references/codes/GB50010-2010_2015_.pdf`。

| 条文 | PDF 页 / 原书页 | 本模块使用范围 |
| --- | --- | --- |
| 6.2.1 | 49 / 34 | 平截面等基本假定 |
| 6.2.2 | 51 / 36 | 单轴作用和截面对称的适用前提 |
| 6.2.5 | 52 / 37 | 附加偏心距 `ea = max(20, h / 30)` |
| 6.2.6 | 52 / 37 | 等效矩形混凝土受压应力图 |

## 明确未覆盖项

- 6.2.3、6.2.4 的二阶效应条件与挠曲附加弯矩；
- 双向偏心；
- 最小配筋、箍筋构造、抗震及其他构造验算；
- 2024 年局部修订和现行通用规范的逐条差异核对。

因此结果和所有证据均标记为 `REVIEW_REQUIRED`，不得直接作为完整工程设计结论。
