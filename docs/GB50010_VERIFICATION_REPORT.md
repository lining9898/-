### 3.7 界限相对受压区高度 ξb（条文 6.2.7）

#### PDF 原文（第53页）

**6.2.7** 纵向受拉钢筋屈服与受压区混凝土破坏同时发生时的相对界限受压区高度 ξb 应按下列公式计算：

**1 钢筋混凝土构件**

**有屈服点普通钢筋**：

ξb = β1 / (1 + fy / (Es · εcu))  **(6.2.7-1)**

式中：
- ξb —— 相对界限受压区高度，取 xb / h0
- xb —— 界限受压区高度
- h0 —— 截面有效高度
- Es —— 钢筋弹性模量，按本规范表 4.2.5 采用
- εcu —— 非均匀受压时的混凝土极限压应变，按本规范公式 (6.2.1-5) 计算
- β1 —— 系数，按本规范第 6.2.6 条的规定计算

#### 代码中的公式 vs PDF 原文

**代码中的公式**：
```typescript
const xiB = concrete.beta1 / (1 + steel.fy / (steel.Es * 0.0033));
```

**PDF 原文公式 (6.2.7-1)**：
```
ξb = β1 / (1 + fy / (Es · εcu))
```

**验证计算（HRB400 + C30）**：
- β1 = 0.80
- fy = 360 MPa
- Es = 200000 MPa
- εcu = 0.0033

ξb = 0.80 / (1 + 360 / (200000 × 0.0033))
   = 0.80 / (1 + 360 / 660)
   = 0.80 / 1.5455
   = 0.5177 ≈ 0.518 ✅

### 3.8 受压区高度 x（条文 6.2.10）

#### PDF 原文（第54-56页）

**6.2.10** 矩形截面或翼缘位于受拉边的倒 T 形截面受弯构件，其正截面受弯承载力应符合下列规定：

**混凝土受压区高度应按下列公式确定**：

α1 · fc · b · x = fy · As - fy' · As' + fpy' · Ap' - (σp0 - fpy') · Ap'  **(6.2.10-2)**

对于仅配置受拉钢筋的矩形截面受弯构件（As' = 0, Ap' = 0），简化为：

**α1 · fc · b · x = fy · As**

因此：

**x = fy · As / (α1 · fc · b)**

```typescript
const x = (steel.fy * As) / (concrete.alpha1 * concrete.fc * input.b);
```

**PDF 原文公式 (6.2.10-2) 简化形式**：
```
x = fy · As / (α1 · fc · b)
```

### 3.10 最小配筋率 ρmin（条文 8.5.1）

#### PDF 原文（第124页）

**8.5.1** 钢筋混凝土结构构件中纵向受力钢筋的配筋百分率 ρmin 不应小于表 8.5.1 规定的数值。

**表 8.5.1 纵向受力钢筋的最小配筋百分率 ρmin (%)**

| 受力类型 | 最小配筋百分率 |
|---|---|
| 受压构件 - 全部纵向钢筋（500MPa级） | 0.50 |
| 受压构件 - 全部纵向钢筋（400MPa级） | 0.55 |
| 受压构件 - 全部纵向钢筋（300/335MPa级） | 0.60 |
| 受压构件 - 一侧纵向钢筋 | 0.20 |
| **受弯构件、偏心受拉、轴心受拉构件一侧的受拉钢筋** | **0.20 和 45ft/fy 中的较大值** |

**注**：
1. 受压构件全部纵向钢筋最小配筋百分率，当采用 C60 以上强度等级的混凝土时，应按表中规定增加 0.10
2. 板类受弯构件（不包括悬臂板）的受拉钢筋，当采用强度等级 400MPa、500MPa 的钢筋时，其最小配筋百分率应允许采用 **0.15 和 45ft/fy 中的较大值**
3. 偏心受拉构件中的受压钢筋，应按受压构件一侧纵向钢筋考虑
4. **受压构件的全部纵向钢筋和一侧纵向钢筋的配筋率以及轴心受拉构件和小偏心受拉构件一侧受拉钢筋的配筋率均应按构件的全截面面积计算**
5. **受弯构件、大偏心受拉构件一侧受拉钢筋的配筋率应按全截面面积扣除受压翼缘面积 (bf' - b)hf' 后的截面面积计算**
6. 当钢筋沿构件截面周边布置时，"一侧纵向钢筋"系指沿受力方向两个对边中一边布置的纵向钢筋

#### 关键发现：配筋率计算基准面积

**规范注5明确规定**：
> 受弯构件、大偏心受拉构件一侧受拉钢筋的配筋率应按**全截面面积扣除受压翼缘面积**后的截面面积计算

对于**矩形截面**（无受压翼缘），即按**全截面面积 b×h** 计算，**不是 b×h0**。

#### 代码中的公式 vs PDF 原文

**代码中的公式**：
```typescript

```

**PDF 原文要求**：

#### 发现的 BUG

**BUG 1：百分数转换错误**

代码中 `45 * ft / fy * 100 / 100` 的计算逻辑有误。

- fy = 360 MPa
- 45 × 1.43 / 360 = 0.17875（这是百分数的数值部分，即 0.17875%）

```

rhoMin = 0.20 / 100 = 0.002
```

代码中使用 `b × h0`，但规范注5明确要求使用 `b × h`（全截面面积）。

#### 正确公式

## 七、发现的原计算公式错误

### 7.1 BUG 1：最小配筋率百分数转换错误

**位置**：`src/core/beam/flexure.ts` 第 214 行

**原代码**：
```typescript
const rhoMin = Math.max(0.2, 45 * concrete.ft / steel.fy * 100) / 100;
```

**错误分析**：
- 规范原文：ρmin = max(0.20%, 45·ft/fy %)
- 45 × ft / fy 的结果是百分数的数值部分（如 0.17875 表示 0.17875%）
- 代码中又乘以 100，变成 17.875，然后除以 100 得到 0.17875
- 这被当作小数使用，即 17.875%，**完全错误**

**以 C30 + HRB400 为例**：
- ft = 1.43 MPa, fy = 360 MPa
- 45 × 1.43 / 360 = 0.17875（这是百分数的数值，即 0.17875%）
- 代码计算：`Math.max(0.2, 0.17875 * 100) / 100 = Math.max(0.2, 17.875) / 100 = 0.17875`
- 结果：rhoMin = 0.17875 = 17.875% ❌
- 正确：rhoMin = max(0.20%, 0.17875%) = 0.20% = 0.002 ✅

**影响**：
- 对于 C30 + HRB400，代码算出 AsMin ≈ 207.8 mm²
- 正确值应为 AsMin = 0.002 × 250 × 500 = 250 mm²
- **误差约 17%**

### 7.2 BUG 2：最小配筋面积计算基准面积错误

**位置**：`src/core/beam/flexure.ts` 第 215 行

**原代码**：
```typescript
const AsMin = rhoMin * input.b * h0 / 100;
```

**错误分析**：
- 规范 8.5.1 注5明确规定：受弯构件一侧受拉钢筋的配筋率应按**全截面面积**计算
- 对于矩形截面，即按 b × h 计算，**不是 b × h0**
- 代码中使用 h0（有效高度），不符合规范要求

**以 C30 + HRB400 为例**：
- b = 250 mm, h = 500 mm, h0 = 465 mm
- 代码计算：AsMin = 0.002 × 250 × 465 = 232.5 mm²（如果 rhoMin 正确）
- 正确计算：AsMin = 0.002 × 250 × 500 = 250 mm²
- **误差约 7%**

### 7.3 修复方案

**正确代码**：
```typescript
// 最小配筋率（百分数数值）
const rhoMinPercent = Math.max(0.20, 45 * concrete.ft / steel.fy);
// 转换为小数
const rhoMin = rhoMinPercent / 100;
// 最小配筋面积（按全截面面积 b×h）
const AsMin = rhoMin * input.b * input.h;
```

**修复后的验证**（C30 + HRB400, b=250, h=500）：
- rhoMinPercent = max(0.20, 45 × 1.43 / 360) = max(0.20, 0.17875) = 0.20%
- rhoMin = 0.20 / 100 = 0.002
- AsMin = 0.002 × 250 × 500 = 250 mm² ✅
