# 混凝土规范版本待复核

仓库收录的是 GB 50010-2010（2015 年版）PDF。住建部 2024 年第 62 号公告批准局部修订，自 2024-08-01 起实施，并将名称、编号改为《混凝土结构设计标准》GB/T 50010-2010。公告见[住建部文告](https://www.mohurd.gov.cn/file/2024/20240822/a015dc08-eaf2-474a-81c1-c4454e3b220c.pdf)。现行设计还须核对相关强制性通用规范，不能只按旧版 PDF 判断。

目前矩形梁受弯、受剪和 T 形梁的计算数值仍按仓库 2015 年版材料参数与公式生成。旧版证据的逐条核对记录予以保留，但三个混凝土计算器的整体状态均为 `REVIEW_REQUIRED`；证据来源标为 `superseded`。此处理不表示 2024 修订必然改变每个公式，仅表示尚未完成差异核查。

继续开发柱、板、基础、楼梯和墙模块前，应取得可公开核验的 2024 修订条文与相应通用规范文本，建立条文版本对应表，并针对材料等级、适用条件、限值及边界工况增加独立回归样例。检索样例通过不能自动升级总状态。
