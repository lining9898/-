# 矩形箍筋柱轴压单项验算范围

依据仓库 `references/codes/GB50010-2010_2015_.pdf` 的 PDF 第 57-58 页，核对了 2015 年版 GB 50010 第 6.2.15 条的承载力公式、稳定系数表及纵筋率超过 3% 的面积修正。检索索引记录页码和工程摘要，并用独立数值样例反查函数；摘要不是规范原文，状态维持 `REVIEW_REQUIRED`。

输入矩形截面尺寸、按项目另行确定的计算长度、全部纵筋面积、轴向压力设计值，以及混凝土与钢筋抗压强度设计值。采用短边计算 `l0/b`；两档之间向较大长细比档取稳定系数，不在表列最大比值 50 之外外推。只在 `As/A > 3%` 时将混凝土计算面积取为 `A - As`。页面给出 `0.9 * phi * (fc * Acalc + fy' * As) / 1000` 的单项承载力，单位为 kN。

本模块不自动选取材料强度或计算长度，不校核偏心、弯矩、配筋及箍筋构造、抗震要求，也未完成 GB/T 50010-2010（2024 年版）局部修订与 GB 55008-2021 的差异核查。单项满足不代表完整设计通过。
