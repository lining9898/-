# 钢梁三项验算范围

来源：济南市住建部门公开的 [GB 50017-2017 扫描件](https://jncc.jinan.gov.cn/attach/0/c24799cca3194d3ba1d87c72caa1c3ef.pdf)。本次逐页核对 PDF 第 54、55、57 页的第 6.1.1、6.1.3、6.2.2 条；网页摘要不是规范原文，校核状态保持 `REVIEW_REQUIRED`。

当前仅支持等厚双翼缘、腹板居中的对称工字形截面，绕强轴单向受弯。按几何尺寸计算毛截面面积、惯性矩、截面模量和中和轴处半截面面积矩。受弯采用弹性系数 1，受剪使用腹板中和轴处剪应力；整体稳定仅代入用户提供的最终系数。输入的弯矩和剪力应为设计值。

未自动计算钢材强度设计值、截面板件宽厚比等级、附录 C 整体稳定系数及其适用条件，也未检查局部稳定、组合应力、挠度、疲劳、连接、防火或抗震。单项满足不构成完整钢结构设计结论。后续增加规范时，应记录版本、来源 PDF、页码、适用条件、独立数值样例和未覆盖条件，再将规则加入检索索引及函数审计；不能因检索到文本就将计算标为 `VERIFIED`。
