## 八、受压区高度 x 和正截面受弯承载力 Mu（条文 6.2.10）

### 候选依据

| 项目 | 内容 |
|---|---|
| 规范名称 | 混凝土结构设计规范 |
| 规范编号 | GB 50010-2010（2015年版） |
| 条文号 | 6.2.10 |
| 条文内容 | 矩形截面或翼缘位于受拉边的倒T形截面受弯构件 |

### 搜索到的公式

**式（6.2.10-1）力平衡**：
```
α1 · fc · b · x = fy · As
```

**式（6.2.10-2）弯矩承载力**：
```
M ≤ Mu = α1 · fc · b · x · (h0 - x/2)
```
或等价形式：
```
M ≤ Mu = fy · As · (h0 - x/2)
```

**式（6.2.10-3）适用条件1**：
```
x ≤ ξb · h0
```
（防止超筋破坏）

**式（6.2.10-4）适用条件2**：
```
As ≥ As,min
```
（防止少筋破坏）

### 当前代码中的公式 vs 搜索值

**代码中的计算**：
```
rhoMin = max(0.2, 45 * ft / fy * 100) / 100
AsMin = rhoMin * b * h0 / 100
```

等等，让我重新检查代码中的公式：
```
const rhoMin = Math.max(0.2, 45 * concrete.ft / steel.fy * 100) / 100;
const AsMin = rhoMin * input.b * h0 / 100;
```

这里有一个**潜在问题**：
- 规范原文：ρmin = max(0.20%, 45·ft/fy %)
- 代码中：`45 * ft / fy * 100 / 100` = `45 * ft / fy`

让我验证：C30 + HRB400
- 45 × 1.43 / 360 = 0.1788%
- max(0.20%, 0.1788%) = 0.20%

代码中 `Math.max(0.2, 45 * 1.43 / 360 * 100) / 100`
= `Math.max(0.2, 17.875) / 100`
= `17.875 / 100`
= `0.17875`

**这里有问题！** 代码中 `45 * ft / fy * 100` 的计算结果是 17.875，不是 0.17875%。

让我重新理解代码：
```
const rhoMin = Math.max(0.2, 45 * concrete.ft / steel.fy * 100) / 100;
```
= `Math.max(0.2, 45 * 1.43 / 360 * 100) / 100`
= `Math.max(0.2, 17.875) / 100`
= `0.17875`

这意味着 rhoMin = 0.17875 = 17.875%？？这明显不对。

等一下，让我重新理解。规范说的是 ρmin = max(0.20%, 45ft/fy%)。

45ft/fy = 45 × 1.43 / 360 = 0.1788（这是一个百分数，即 0.1788%）

所以 ρmin = max(0.20%, 0.1788%) = 0.20%

代码中：
- `45 * ft / fy` = 45 × 1.43 / 360 = 0.1788（这是百分数的数值部分）
- `45 * ft / fy * 100` = 17.88（这变成了千分数？）
- `Math.max(0.2, 17.88) / 100` = 0.1788

所以代码中 rhoMin = 0.1788，即 17.88%？这不对。

让我再看看代码的上下文：
```
const AsMin = rhoMin * input.b * h0 / 100;
```

如果 rhoMin = 0.1788，那么 AsMin = 0.1788 × 250 × 465 / 100 = 207.8 mm²

而正确计算应该是：
ρmin = 0.20% = 0.002
AsMin = 0.002 × 250 × 465 = 232.5 mm²

**这里有 BUG！** 代码中的公式有误。

让我再仔细看一遍代码...

```typescript
const rhoMin = Math.max(0.2, 45 * concrete.ft / steel.fy * 100) / 100;
```

45 * 1.43 / 360 * 100 = 17.875
Math.max(0.2, 17.875) = 17.875
17.875 / 100 = 0.17875

所以 rhoMin = 0.17875

然后：
```
const AsMin = rhoMin * input.b * h0 / 100;
```
= 0.17875 * 250 * 465 / 100
= 207.8 mm²

而正确的应该是：
ρmin = max(0.20%, 45ft/fy%) = max(0.20%, 0.1788%) = 0.20% = 0.002
AsMin = 0.002 * 250 * 465 = 232.5 mm²

**确认有 BUG**。代码中 `45 * ft / fy` 的结果是百分数的数值（如 0.1788 表示 0.1788%），但代码又乘了 100，变成了 17.88，然后除以 100 得到 0.17875，这被当作小数使用（即 17.875%），完全错误。

正确的代码应该是：
```
const rhoMinPercent = Math.max(0.2, 45 * concrete.ft / steel.fy); // 百分数数值
const rhoMin = rhoMinPercent / 100; // 转为小数
const AsMin = rhoMin * input.b * h0; // 直接用小数乘面积
```

或者：
```
const rhoMin = Math.max(0.002, 0.45 * concrete.ft / steel.fy); // 直接小数
const AsMin = rhoMin * input.b * h0;
```

**这是一个需要向用户报告的重要问题。**

### 冲突/注意事项

- **发现代码 BUG**：最小配筋率计算公式存在错误。
  - 规范原文：ρmin = max(0.20%, 45ft/fy %)
  - 代码中错误地将百分数转换搞混，导致计算结果偏小
  - 以 C30 + HRB400 为例：代码算出 AsMin ≈ 207.8 mm²，正确值应为 232.5 mm²
- **最小配筋率的计算基准**：规范注4说明"受弯构件一侧受拉钢筋的配筋率应按全截面面积扣除受压翼缘面积后的截面面积计算"。对于矩形截面，即按全截面面积 b×h 计算（不是 b×h0）。但代码中用的是 b×h0。
  - 这一点存在争议：部分教材用 b×h0，部分用 b×h。规范原文说"按全截面面积计算"，应该是 b×h。
  - **需要用户确认**：As,min 的计算是用 b×h 还是 b×h0？
