# 规范导入接口（预留）

此目录预留用于未来导入规范 PDF 文件。

## 计划功能

1. 上传 GB 50010、GB 50009、GB 50007 等规范 PDF
2. 解析规范条文、公式、表格
3. 建立条文索引，供计算内核引用
4. 每条计算步骤可追溯到具体规范条文和页码

## 当前状态

`src/codes/clause-index.ts` 提供 GB 50010 的少量人工核对 PDF 起始页及关键词索引，供网页检索和计算依据跳转。该索引不包含经过校核的规范原文，不能替代条文核验或计算依据。PDF 导入、全文解析、向量检索和生成式问答尚未实现；索引项保持 `REVIEW_REQUIRED`。
