# 规范导入接口（预留）

此目录预留用于未来导入规范 PDF 文件。

## 计划功能

1. 上传 GB 50010、GB 50009、GB 50007 等规范 PDF
2. 解析规范条文、公式、表格
3. 建立条文索引，供计算内核引用
4. 每条计算步骤可追溯到具体规范条文和页码

## 当前状态

`src/codes/clause-index.ts` 提供 GB 50010 的少量人工核对 PDF 起始页。`src/codes/rule-corpus.ts` 保存人工整理的规则摘要（非规范原文），`src/codes/retrieve-rules.ts` 进行本地中文词项检索，`src/audit/function-audit.ts` 用独立边界算例反查计算函数。每项结果附来源页码与函数实际值；未覆盖项明确显示，不会因检索命中或样例通过而自动升级规范校核状态。

此版本不上传 PDF 到第三方，也没有向量嵌入或大模型生成。原 PDF 的可提取文本存在乱码和公式缺损，不可直接批量灌入知识库。后续如需全文语义 RAG，必须先完成 OCR/表格公式校对，再接入检索模型和服务端密钥管理。
